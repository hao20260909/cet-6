# 听辨错误分类

每条错误先选一个主要代码；确有需要时再加一个次要代码。错误明细直接记在精听复盘中，本页只维护分类，避免重复记录。

| 代码 | 类型 | 判断线索 | 针对性练习 |
| --- | --- | --- | --- |
| S1 | 音素或词边界误听 | 知道这个词，但把音听成别的词或断错位置 | 对照原文，截取短片段，辨音后原速盲听 |
| S2 | 连读、弱读、失爆等语流现象 | 单词单独认识，放进句子便漏听 | 标出实际发音变化，模仿跟读，再整句听写 |
| V1 | 词汇或短语不熟 | 看文本仍不懂，或无法快速识别词义 | 记录语境义与声音，按短语复听 |
| G1 | 句法、否定或指代 | 词听见了，但人物、否定范围或句子关系弄错 | 划分意群，标出主干、否定和指代对象 |
| D1 | 转折与修正 | 记住转折前内容，漏掉修正或最终重点 | 同时写出转折前后观点，复述最终立场 |
| D2 | 原因与结果 | 漏掉原因、把结果当原因，或归错说话人 | 画“谁 / 什么事：原因 → 结果”，定位原句 |
| D3 | 时间与顺序 | 日期、时长、先后、原定与变更混淆 | 写时间线，区分旧安排与最终安排 |
| Q1 | 同义改写或选项干扰 | 理解对话，但没对应改写，或被原词干扰 | 对照证据句与选项，写明改写或偷换点 |
| A1 | 注意与短时记忆 | 当时走神或信息过载，短片段重听即可理解 | 缩短片段，只记人物、动作和关键关系 |

## 使用方式

1. 先看证据，区分“没听出声音”“没理解关系”和“理解了但选错”。
2. 例如已听清转折词却沿用旧观点，主要记 D1；转折词本身因弱读没听到，可主要记 S2、次要记 D1。此为分类示意，不是真题记录。
3. 无法判断时写“待诊断”，保留误听及时间戳，核对后再分类。
4. 每周回看日志，找出反复出现的 1–2 个代码，并写下一次对应练习。是否改善以原速盲听结果为依据。

# 真题素材目录

目前未提供任何真题音频、试题、原文或答案。本目录只提供扩展约定，不预设任何年份套题已经存在。

## 素材到位后再建目录

建议路径：`materials/YYYY-MM-set-N/`。年月、套别经来源确认后填写；不确定时可暂用 `materials/unverified-001/`，不要猜套别。

每套资料包含一份 `README.md`，复制自[素材信息模板](../templates/material.md)。按实际需要添加：

- `audio/`：音频或音频位置说明。
- `questions/`：试题或来源说明。
- `transcript/`：可核对原文或来源说明。
- `answers/`：答案、解析或来源说明。

这些子目录当前尚未创建。缺少的文件在素材信息页写“未提供”，保留后续补充空间。素材ID建议与套题目录名一致；对话编号用 `long-01`、`long-02`，以实际材料为准。

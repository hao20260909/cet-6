## 每次训练怎么记

1. 复制每日模板到 `logs/YYYY/YYYY-MM-DD.md`，填当天目标、素材和用时；同日训练追加在同一文件中。
2. 首听先不看文本，记录答案、信心和依据。挑一段长对话，用精听模板建立 `reviews/YYYY-MM-DD-素材ID-long-01.md`。
3. 分段听写，标出转折后的重点、原因和结果、时间与先后顺序。核对可靠原文或答案后，再填纠正和证据。
4. 每个主要错误选一个分类代码；只把需要复习的词或短语加入声音记录，附素材与时间戳。
5. 回到当天日志，链接复盘并写下一次具体任务。建议次日与一周后原速盲听，按结果调整复习时间。

时间戳统一用 `mm:ss–mm:ss`；素材ID在素材、日志、复盘和词汇记录中保持一致。没有原文或可靠答案时标“待核对”，不猜填。

## 低维护约定

- 日志只记实际训练；计划、未完成、已完成分开写。没有训练的日期无需补建文件。
- 路径中的 `YYYY`、`YYYY-MM-DD`、素材ID等是命名占位符，使用时替换；模板中的“待填写”也需据实填写。
- 每周用几分钟回看日志，选最常见的 1–2 类错误作为下周重点，不必维护额外统计表。
- [2026-11-02 日志](logs/2026/2026-11-02.md)仅为待填写入口，无训练结果。
- 目前未收录真题音频、试题、原文或答案。素材到位后按[目录说明](materials/README.md)添加。
